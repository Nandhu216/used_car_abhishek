================================================================================
USED CAR MARKETPLACE SYSTEM - DATA FLOW DIAGRAMS (DFD)
================================================================================
This file contains Mermaid diagram code for DFD Level 0, Level 1, and
Level 1.1 through 1.n. Copy each Mermaid block into a Mermaid-supported viewer
(e.g. GitHub, Mermaid Live Editor, VS Code Mermaid extension) to render.

Notation:
  [External Entity]  (Process)  [(Data Store)]  -->|Flow label|
================================================================================


--------------------------------------------------------------------------------
DFD LEVEL 0 - CONTEXT DIAGRAM (ENTIRE SYSTEM AS ONE PROCESS)
--------------------------------------------------------------------------------
Shows the Used Car Marketplace System as a single process with external
entities (Buyer, Seller, Admin) and high-level data flows.

```mermaid
flowchart LR
    subgraph External Entities
        Buyer[Buyer]
        Seller[Seller]
        Admin[Admin]
    end

    System((Used Car Marketplace System))

    Buyer -->|Registration, Login, Profile| System
    Buyer -->|Search/Filter, Favorites, Compare| System
    Buyer -->|Enquiries, Bids, Payment Choice, Delivery Choice| System
    Buyer -->|Damage Reports, My Bids/Orders/Enquiries| System
    System -->|Car Listings, Confirmations, Order Status| Buyer

    Seller -->|Registration, Login, Profile| System
    Seller -->|Add/Edit Listings, Images, Auction Mode| System
    Seller -->|View Enquiries, Accept/Reject Bids| System
    Seller -->|Manage Delivery, Respond to Damage, Mark Sold| System
    System -->|Enquiries, Bids, Notifications| Seller

    Admin -->|Login| System
    Admin -->|Manage Users, Listings, Bids, Payments, Delivery, Damage Reports| System
    Admin -->|Approve/Edit/Remove Listings, Block Users| System
    System -->|Dashboard, Reports, Status| Admin
```

DFD LEVEL 1.5 - CAR LISTING & BIDDING (CROSS-ROLE DATA FLOW)
--------------------------------------------------------------------------------
Shows how Car and Bid data flows between Buyer and Seller.

```mermaid
flowchart LR
    subgraph Buyer Side
        B1[Browse/Search]
        B2[Place Bid]
        B3[Pay for Won Bid]
    end

    subgraph Seller Side
        S1[Add Listing]
        S2[Enable Auction]
        S3[Accept/Reject Bid]
    end

    D2[(Cars)]
    D3[(Bids)]

    S1 --> D2
    S2 --> D2
    D2 --> B1
    B2 --> D3
    D3 --> S3
    S3 --> D2
    S3 --> D3
    D2 --> B3
```
